# **App Name**: StoryQuest Metabook

## Core Features:

- Interactive Welcome Page: Display an engaging welcome page with a central CTA, illustration, and motivational title.
- PDF Upload & Analysis: Allow users to upload PDF stories, with a visually appealing drag & drop interface and animated loading screen that simulates analyzing the chapters and characters.
- Story to Visual Tool: The AI analyzes a text selection and turns that into a suggestion for the visual prompt to be used in story generation, incorporating knowledge of themes and settings.
- Chapter Breakdown with Visuals: Present an interface that visualizes chapters, characters, and settings from the uploaded story.
- Progress Tracking: Visually track user progress with a weekly goal system, displayed as a treasure chest filling up, and celebrate achievements.
- Persistent Header Navigation: Maintain a fixed header with key navigation elements: Library, Profile, and a Condor Quipu mascot.
- Floating Action Button: Implement a continuously visible floating action button for uploading stories, located at the bottom right corner.

## Style Guidelines:

- Primary color: Light pastel blue (#F0F8FF) for the background, creating a soft and inviting atmosphere.
- Accent color: White for CTAs and rewards, offering a contrasting and appealing visual element.
- Secondary Accent color: Dark blue (#00008B) used for secondary buttons.
- Text color: Black (#000000) for optimal readability.
- Dark scheme background: Slightly desaturated darker blue (#5F9EA0) for header, to ensure good contrast against the other page elements.
- Body and headline font: 'PT Sans', a modern, humanist sans-serif for readability and friendly appeal.
- Employ high-density custom icons and illustrations with a focus on clarity, especially around core actions (uploading), mascot (Quipu), and chapters (themed icons).
- Design a mobile-first responsive layout using bubble-shaped, rounded elements to ensure accessibility and create a playful interface that attracts both kids and parents.
- Incorporate subtle animations for user interactions, especially on the welcome page's CTA button and the loading screen.
